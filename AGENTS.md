# AGENTS

## Project purpose

MockApp is a standalone offline browser app for creating Bootstrap-style UI mockups.

## Important working constraints

- Keep the app usable from `file://`.
- Prefer local assets and browser APIs over server dependencies.
- Keep changes small and focused around the app shell, project JSON model, and export behavior.
