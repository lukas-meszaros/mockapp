# Keyboard Shortcuts

## Implemented

- Cmd/Ctrl + N: New project
- Cmd/Ctrl + O: Open project JSON
- Cmd/Ctrl + S: Save project
- Cmd/Ctrl + Shift + S: Save As
- Cmd/Ctrl + Z: Undo
- Cmd/Ctrl + Shift + Z: Redo
- Cmd/Ctrl + Y: Redo
- Cmd/Ctrl + C: Copy selected component
- Cmd/Ctrl + V: Paste component
- Cmd/Ctrl + D: Duplicate selected component
- Delete: Delete selection
- Backspace: Delete selection when not editing a field

## Planned follow-up

- Cmd/Ctrl + X cut
- Cmd/Ctrl + A select all
