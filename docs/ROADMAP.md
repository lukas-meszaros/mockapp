# Roadmap

## MVP

- buildless offline app shell
- vendored Bootstrap and Bootstrap Icons
- searchable component palette
- nested layout model
- page management
- structured property inspector
- autosave and JSON open/save
- HTML, PNG, SVG, and JSON export
- preview mode

## Version 1.x improvements

- richer Bootstrap coverage
- drag reordering between siblings
- multi-select editing and mixed-value inspector states
- alignment and distribution tools
- context menu
- recent project reopening with persistent file handles where supported
- autosave recovery UI
- toolbar/menu command parity with all documented shortcuts

## Future features

- custom reusable components
- comments and annotations
- page links and prototype flows
- import existing Bootstrap HTML
- plugin architecture
- theming and dark editor mode
- optional collaborative workflows
